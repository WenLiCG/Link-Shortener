# 域名时间筛选预设

## 目标

在域名控制台的“时间”下拉框增加“昨天”和“过去 7 天”，按域名创建日期过滤。

## 范围

- 复用现有 `/api/domains?days=` 参数，不增加依赖或新接口。
- 预设含义（中国标准时间）：`0` 为今天，`-1` 为昨天，正整数 `N` 为含今天的最近 `N` 个自然日。
- 现有 30、90、180、365 天预设同步采用上述“含今天”语义。
- “今天”由现有值 `1` 改为 `0`，使标签与实际结果一致。

## 实现

前端下拉框增加“昨天”（`-1`）和“过去 7 天”（`7`），并将“今天”改为 `0`。

后端筛选逻辑以 `days` 是否存在为判断条件：`0` 精确匹配今天，`-1` 精确匹配昨天，正整数匹配从“今天减 N-1 天”至今天。其余筛选条件保持不变。

## 验证

添加覆盖今天、昨天和过去 7 天边界的自动化测试；运行完整测试、类型检查和构建。
